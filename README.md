# Sign Language Psychologist 


## 🧠 Overview
This project implements a chatbot avatar designed to support individuals with hearing impairments using sign language and psychology-driven conversational models.  
Built as part of the MS-AIML program, it combines AI, NLP, and accessibility-focused design.

---

## 🚀 Features
- NLP chatbot backend built in Python  
- Visual sign-language avatar integration  
- AI-driven sentiment and psychology-based response generation  
- Modular architecture with API and UI separation  
- Extensible for future LLM or generative model integration

---

## 🏗️ Project Structure
```txt
MS-AIML-LJMU/
│
├── app.py / backend.py # Entry point for chatbot application
├── models/ # Trained ML / NLP models
├── ui/ # HTML, CSS, JS frontend (avatar & chat UI)
├── data/ # Sample datasets or training data
├── docs/ # Reports, proposals, academic files
├── utils/ # Helper modules
└── requirements.txt
```

## ⚙️ Setup

### Prerequisites
- Python 3.8+
- Virtual environment recommended

### Installation
```bash
git clone https://github.com/sunaynatalreja/MS-AIML-LJMU.git
cd MS-AIML-LJMU
pip install -r requirements.txt
```
## Run

``` bash
python app.py
```

Access the UI via browser (default: http://127.0.0.1:5000).

## Usage

- Start the backend service
- Open the chatbot UI
- Interact using ISL sign language letters
- Observe avatar sign-language responses
